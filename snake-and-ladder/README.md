# Snake and Ladder – LLD Implementation

This module implements a **Snake and Ladder** game in Java using clean object‑oriented design and design patterns.

- The board is `n x n`.
- There are `n` snakes and `n` ladders placed randomly.
- Supports multiple players and two difficulty levels: **EASY** and **HARD**.
